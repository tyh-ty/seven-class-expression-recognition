# 七类面部表情识别系统

这是一个独立运行的本地七类面部表情识别系统，不接入教学系统。

当前版本采用两阶段方案：YuNet 定位人脸并去除重复框，分类器是在本机微调得到的纯 ViT-S/16 ONNX 模型，将扩展后的 `224 x 224` 灰度方形人脸分类为 7 类可见表情。摄像头模式会对同一张脸做自适应多帧融合，图片模式显示原始单帧结果。所有图像都只在本机处理。

表情分类器是纯 Vision Transformer：使用 `timm` 的 ImageNet-21K/ImageNet-1K 预训练 ViT-S/16 作为骨干，以 FERPlus 七类数据训练，并使用 RAVDESS、CREMA-D、KDEF、ExpW 和 eNTERFACE 数据适配，保留原有的人物、视频与数据划分。当前正式模型是 `models/vit_emotion_seven_fp32.onnx`，由 eNTERFACE 适配第 2/6 轮参数平均得到，运行时只推理一个模型。7 类为愤怒、厌恶、恐惧、开心、中性、悲伤和惊讶。

## 启动

**Windows 10/11（Intel/AMD 64 位）双击 `启动服务.cmd` 即可。** 启动器自动检查模型、配置项目内的独立 Python 和推理依赖，完成 CPU 自检后启动服务并打开浏览器。重复启动复用本项目服务，端口冲突自动切换。使用时保留启动窗口，关闭窗口或按 Ctrl+C 停止。

不需要手动安装 Python，也不需要 GPU 或 CUDA。首次配置使用 `deployment/cache/` 中的安装资源；缺少缓存时自动联网下载。Microsoft C++ 运行库缺失时会自动调用官方安装包，可能需要管理员确认。详细说明见 [部署说明.md](部署说明.md)。

迁移到实验室电脑，先制作包含模型和离线环境资源的部署包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-deployment.ps1
```

将 `dist/` 中生成的 ZIP 完整解压到目标电脑，双击 `启动服务.cmd`。不要复制整个训练环境，也不要仅复制 HTML。当前自训练模型必须随部署包携带；`download-model.ps1` 仅下载公共基线，无法补齐默认 ViT。

开发人员仍可使用已有 Python 环境运行：

```powershell
python -m pip install -r requirements.txt
python .\server.py
```

默认页面为 <http://127.0.0.1:8765>，启动器切换端口时以窗口提示为准。摄像头模式需要授予摄像头权限。启动日志保存在 `output/startup.log`。

## 结果边界

模型识别的是面部表情模式，不是对真实心理状态的测量。正式研究前，应在目标数据上重新评估并报告每类 F1、宏平均 F1、混淆矩阵、光照/姿态/遮挡鲁棒性，以及跨数据集泛化结果。

模型与类别说明见 `models/README.md`。

## 自训练 Transformer

仓库已经包含独立的 ViT-S/16 微调、按人员拆分、宏平均 F1 评估、混淆矩阵和 ONNX 导出流程。训练环境与运行系统隔离。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-training-env.ps1
```

数据准备和训练步骤见 `training/README.md`。2026-09-28 早上发布的 FP32 模型在事先冻结的 2,610 张 ExpW 最终测试照片上准确率为 **51.80%**，宏平均 F1 为 **0.4508**；恐惧召回率为 **15.96%**，厌恶为 **8.20%**，仍然较弱。在 6 名未见人物的 180 段 eNTERFACE 视频上，整段预测准确率为 **42.78%**，连续正确显示至少半秒的片段占 **30.56%**。该视频集是受控情绪语音、六类且没有中性，不代表自然摄像头七类准确率。

用于选择模型的 196 张真实眼镜照片准确率为 **54.08%**，宏平均 F1 为 **0.4689**；恐惧只有 7 张，不能据此保证真实眼镜人群的效果。合成眼镜增强不等于真实眼镜测试，系统仍会误判。完整逐类结果、测试边界和部署验证见 [夜间训练与测试结果](output/overnight-validation-20260928/夜间训练与测试结果.md)。中午追加实验见 [论文方法与实验记录](training/noon-20260928/论文方法与实验记录.md)，实验候选只有通过照片、视频与实际 CPU 检查才会替换正式模型。研究记录不进入部署 ZIP。

中午阶段的训练、照片对照和538段视频复核已经完成，新增候选均未满足替换条件，继续保留上述早上FP32版本。最终结论、七类指标和唯一部署包校验见 [中午训练与验证结果](output/noon-validation-20260928/中午训练与验证结果.md)。自然场景七类高准确率的目标尚未达到。
